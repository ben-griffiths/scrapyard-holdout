# Scrapyard Holdout

A 2D zombie survival colony builder that runs in the browser. Direct your crew to chop, scavenge, build and cook; automate with conveyors, machines and a power grid; and hold the scrapyard through ever-bigger nights.

**Play:** open `index.html`, or visit the GitHub Pages site for this repo.

## Controls
- **1 / 2 / 3** speed, **0** or **Space** pause
- **4–8** Camp, Crafting, Defense, Machines, Power
- **Q** select, **C** chop, **V** scavenge, **X** demolish, **R** rotate
- **Tab** crew, log and guide · **WASD** pan · wheel or pinch to zoom

Saves automatically in your browser.
